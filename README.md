# 🌌 Nosso Universo

Uma experiência imersiva e personalizada criada para Mikelly.

## 🎯 Conceito

Não é só um site — é uma experiência narrativa cinematográfica onde você entra em um universo infinito cheio de mensagens carinhosas e memoráveis.

## 🧱 Estrutura

- **Intro Screen**: Abertura cinematográfica com animações suaves
- **Universe Screen**: Hub interativo com:
  - 🌟 Estrelas clicáveis (elogios categorizados)
  - 🪐 Planetas (Desejo, Amor, Memórias)
  - 🚀 Foguete interativo
  - 👨‍🚀 Astronauta flutuante
  - 🎵 Player de música ambiente
  - ✨ Animações dinâmicas e efeitos parallax

## 🛠️ Tech Stack

- **React 18** com TypeScript
- **Tailwind CSS** para estilização
- **Framer Motion** para animações
- **Vite** como build tool
- **Vercel** para deploy

## 🚀 Como Executar

1. Instale as dependências:
```bash
npm install
```

2. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

3. Abra [http://localhost:3000](http://localhost:3000) no seu navegador

## 📦 Build para Produção

```bash
npm run build
```

## 🎨 Customização

### Mensagens
Edite o arquivo `src/components/InteractiveElements.tsx` para adicionar mais mensagens personalizadas.

### Cores
Modifique `tailwind.config.ts` para ajustar a paleta de cores.

### Animações
Ajuste os valores de `duration` e `transition` nos componentes para mudar o timing das animações.

## 🌟 Features

- ✨ Animações suaves com Framer Motion
- 🎵 Suporte a música ambiente (liga/desliga)
- 📱 Responsivo para mobile e desktop
- 🎬 Transições cinematográficas
- 💖 Totalmente personalizado
